# Soslay — Social Slay Tennis Club

Website komunitas tenis Soslay (Jakarta & Bali): halaman publik, member area, dan (nanti) admin panel.

- [`web/`](web/) — aplikasi Next.js 16 (App Router · TypeScript · CSS Modules · GSAP). Lihat [web/README.md](web/README.md).
- [`docs/`](docs/) — design system, PRD, dan rencana implementasi.

```bash
cd web
npm install
npm run dev   # http://localhost:3000
```

Desain: Figma "Soslay - Development".
